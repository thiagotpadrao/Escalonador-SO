# Process Scheduler (OS)

A lightweight simulation of a process scheduler for operating systems. This project demonstrates core scheduling algorithms and how processes are managed in a multitasking environment.

## Features

- Support for multiple scheduling algorithms:
  - First-Come, First-Served (FCFS)
  - Shortest Job Next (SJN)
  - Round Robin (RR)
  - Priority Scheduling
- Process queue management
- Customizable time quantum (for RR)

## Technologies

- Language: Java
- No external dependencies
